# Open Source Observer

<img src="/img/projects/opensource-observer.png" alt="Open Source Observer" width="360" />

Open source runs through nearly every production system on Earth, and Open Source Observer is the instrument that watches it work. It started in 2023 as the most sophisticated data pipeline ever built for measuring open source supply chains, monitoring GitHub and package managers like npm and crates, and computing dozens of metrics on open source projects. It's now being rebuilt with more depth (novel machine learning techniques that analyze proprietary code from its binaries, bytecode, and bundles), more breadth (Java, C/C++, Python, and more), and more scale (AI agents exploring at scale).
